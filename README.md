# SeqVision

SeqVision is an open-source educational platform for visually explaining how sequence models compute. It is designed around interactive, equation-synchronized walkthroughs for LSTM, xLSTM, GRU, Mamba, Transformer, ConvLSTM, and TCN architectures.

The full production blueprint lives in [`src/docs/product-spec.md`](src/docs/product-spec.md). It includes the PRD, system architecture, UI/UX specification, rendering pipeline, animation pipeline, tensor computation pipeline, API specification, roadmap, performance plan, testing plan, and deployment strategy.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.
