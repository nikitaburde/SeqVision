# SeqVision

SeqVision is an open-source platform for interactive visualization of sequence models, with equation-synchronized animations and deep tensor inspection.

## Highlights
- Model explorers for LSTM, xLSTM, GRU, Mamba, Transformer, ConvLSTM, and TCN.
- Chapter-based walkthroughs inspired by educational explorable systems.
- Tensor inspector with shape/value/statistics metadata.
- Compare mode and research mode scaffolds.
- API skeleton for simulation, walkthrough, equation, tensor, dataset, and progress workflows.

## Development

```bash
npm install
npm run dev
```
