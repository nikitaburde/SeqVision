# SeqVision Product Roadmap

## Phase 1 — MVP (Interactive LSTM)
- LSTM model explorer and chapter walkthrough.
- Equation-synced timeline and baseline tensor inspector.
- Core controls (play/pause/step/reset, architecture, hidden units, sequence length).

## Phase 2 — GRU and Transformer
- Add GRU and Transformer explorers.
- Launch compare mode foundation with synchronized timelines.

## Phase 3 — Mamba + xLSTM + Research Foundation
- Ship Mamba flagship selective scan visualization.
- Add xLSTM matrix memory walkthrough.
- Release research workspace with advanced diagnostics.

## Phase 4 — Tensor Inspector Depth + Dataset Expansion
- Expand inspector to distributions, gradients, memory profile, and weight evolution.
- Add multi-dataset support (temperature, energy, traffic, weather, stock, ECG, sensor).

## Phase 5 — Community Ecosystem
- Publish plugin SDK and marketplace.
- Open contribution tracks for models, datasets, and walkthrough content.

## Stretch Goals
- Live PyTorch runtime visualization
- Custom model upload and ONNX ingestion
- Hugging Face integration
- Real-time inference mode
- Explainable AI overlays
- Education course packs
- Notebook integration
- Citation generator
- Animation export
- VR/AR mode
- Collaborative classroom mode
