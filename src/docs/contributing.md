# Contributing to SeqVision

## Engineering Principles
- Keep animation and equation timelines deterministic.
- Every visual operation must map to a computation atom.
- Prefer composable, architecture-agnostic primitives.

## Development Workflow
1. Fork and branch from the latest default branch.
2. Implement focused changes with tests.
3. Run lint and build checks locally.
4. Submit PR with screenshots/GIFs for visualization changes.

## Contribution Areas
- Model walkthrough chapters
- Equation mapping and tensor instrumentation
- Dataset adapters and benchmark presets
- Performance optimization and accessibility improvements
- Documentation and educational content

## Quality Requirements
- Type-safe APIs and runtime validation.
- Unit/integration tests for new logic.
- Accessibility checks for new interactions.
- Performance-aware rendering changes.
